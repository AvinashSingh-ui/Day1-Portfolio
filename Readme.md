# Frontend Developer Portfolio

A simple portfolio website built using **HTML5** as part of Day 1 frontend training.

## Features

* About Me section
* Skills section
* Projects section
* Contact form
* Semantic HTML5
* ARIA accessibility
* Basic SEO

## Technologies Used

* HTML5
* Semantic HTML
* ARIA
* SEO
